# homebrew-descry

Homebrew tap for [Descry](https://descry.app) — a local action firewall for AI coding agents.

## Install

```sh
brew tap Descry-Technologies/descry
brew install descry
```

Or in one step:

```sh
brew install Descry-Technologies/descry/descry
```

## What is Descry?

Descry sits between your AI coding agent (Claude Code, Codex, Cursor) and the tools it calls. It blocks catastrophic shell commands, force-pushes to protected branches, destructive cloud operations, and MCP tool poisoning — in under 30ms, with no LLM on the hot path.
